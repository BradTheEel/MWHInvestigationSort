# Investigation Sort

[Read in English](README.md)

Investigation Sort — мод для Monster Hunter: World Iceborne, который добавляет окно сортировки из Ресурсного центра в меню **«Разместить новое задание → Расследования»**.

Чтобы открыть окно, нажмите **Tab** на клавиатуре или **правый стик (RS/R3)** на геймпаде. Выбранный порядок применяется ко всем страницам списка зарегистрированных расследований выбранного ранга. Отмена сохраняет текущий порядок. Пункт сброса возвращает исходный порядок игры.

Мод разработан с помощью искусственного интеллекта (ИИ).

## Установка

Мод рассчитан на Steam-сборку `15539686` для Windows x64. Требуется Stracker’s Loader.

Скопируйте папку `nativePC` из установочного архива в папку игры. Для удаления закройте игру и удалите файл `nativePC/plugins/InvestigationSort.dll`.

## Сборка из исходников

Запустите скрипт из корня репозитория в PowerShell с Zig 0.13.0.

```powershell
./build.ps1 -ZigPath 'C:/path/to/zig.exe'
```

Готовый файл появится по пути `build/InvestigationSort.dll`. В репозитории есть [исходники и лицензия MinHook](src/vendor/).
